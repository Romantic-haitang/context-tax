# 内部 API 手册

所有接口前缀 `/api/v2`，鉴权用 `Authorization: Bearer <token>`。

## `GET /orders`

分页列出 orders，支持 `page`、`page_size`、`sort`、`filter` 参数。

```json
{ "page": 1, "page_size": 50, "data": [], "total": 0 }
```

错误码：`400` 参数错误，`401` 未授权，`403` 无权限，`404` 不存在，`409` 冲突，`422` 校验失败，`429` 限流，`500` 服务端异常。

限流：每 token 每分钟 600 次，超限返回 `X-RateLimit-Reset`。重试策略：指数退避，首次 200ms，最多 5 次，仅对 `429` 和 `5xx` 重试。
