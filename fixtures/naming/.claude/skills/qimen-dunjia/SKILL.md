# 奇门遁甲断卦

## 什么时候用

用户报了时间并带着一个具体问题要起局的时候。不用于纯理论提问。

## 步骤

1. 确认时间、时区、问题。缺一个就不要往下走。
2. 排盘：定局、布九宫、安九星八门八神。
3. 按九步 SOP 逐一读盘，每步只给一句结论。
4. 最后给整盘判断，并写明依据在哪一宫。

## 反模式

- 不要先给结论再补理由，那是编的。
- 不要在时间不确定时硬排盘。
